## 10. Bot ignition (probe-driven: why no bot ever grew — 2026-07-15)

GrowthProbe (tests/perf/balance/GrowthProbe.ts, kept as a diagnostic) traced the task-8 harness stall to a four-link chain: the kit field's war-torn ceiling (~4–9k capacity) sat BELOW the 10k first rung (no pairs, ever) → placed Settlements were hollow (urban target `floor(pop/10k)` = 0 below 20k — the pair could never FOUND anything) → the planner's labor model double-counted one Voronoi pool (the "new district" split the old one's people) → nations attacked their own farmers into the field margins (labor = the idle pool; unbounded attacks → fallow → famine → repeat).

- [x] 10.1 First rung inside the kit's reach: `settlementLadderBasePop` 10k → 4k (pair 2 ~23k, pair 3 ~64k) — the ladder paces founding, it must never gate out the whole economy
- [x] 10.2 Nuclei anchor the urban target: `foodTargetTiles = max(nucleusCount, pop/perTile)` — a founded town earns its first city tile through the normal CA (shed-gated, paced), and recession never razes a living town's last tile; spec delta in tribal-buildings; test in UrbanGrowth.test.ts
- [x] 10.3 Farmers stay home: `fieldStaffingNeed` (tilled set × farmersPerFieldTile — protects what's worked, ratchets down in war) floors the attack reserve in AiAttackBehavior.calculateAttackTroops; skipped while under attack (survival outranks the harvest); test in EconomyModel.test.ts
- [x] 10.4 Planner labor dedupe: `committedStaffing` (per-nucleus min(people, staffing need)) subtracted from candidate residents (`effectiveResidents`) in lone-farm and pair siting — kills the adjacent-split "district"; test in EconomyModel.test.ts
- [x] 10.5 Probe confirms ignition (verdantia t1800): top nation pop 22k (was 3–7k), awards 2, farms 3, urban 3 = urbanTarget 3, 38 field tiles; harness at DEFAULT knobs re-run for balance-notes

## 11. Playtest iteration 2026-07-19 (spawn crash-and-stall; immortal husk nations)

Probe traced two reports to root causes. (a) The kit nucleus alone caps day-one capacity at ONE tile's yield, so the population crashes toward a few hundred and the plot labor gate then locks the field at that size forever — on mediocre land (suit·soil ≈ 0.1) a spawn flatlined at pop 413 / 2 field tiles for 3000 ticks (the field needs people, the people need the field). (b) A husk nation at single-digit population sits at birth/death equilibrium (capacity ≈ pop) so the exact-zero die-out never fires; and the nation ENCLAVING it never attacks because the AI reserve/trigger gates compare troops to housing-based maxTroops, which a food-bound population never reaches.

- [x] 11.1 Starter field in the spawn kit: `foundCore` pre-claims `startPopulation/farmersPerFieldTile` tiles (nucleus included, the acreage the village's own labor sustains) greedily on the best-suitability frontier, each settled at its climate suitability; claim-viable only, so hostile ground plants fewer (dead-soil spawns keep nucleus-only scarcity). Probe: mediocre-land spawn now holds ~1475 (was: crash to 413); fertile fixture grows past startPopulation from tick one. Test in FoodEconomy.test.ts
- [x] 11.2 Minimum viable population: `minViablePopulation` (100, displays as 10) — a nation with BOTH population and food capacity below it disbands (land reverts to neutral); famine dips with live fields (capacity high) still recover, exact-zero rule unchanged; inert test config sets 0. Tests in FoodEconomy.test.ts (disband + capacity-spares-recovery)
- [x] 11.3 AI mop-up: `AiAttackBehavior.mopUpWeakNeighbor` — a bordering non-friendly AI neighbor dwarfed 20:1 gets a small dedicated force (min(troops/4, max(500, 10× theirs))), bypassing the reserve/trigger gates in both attackBestTarget (nations) and attackRandomTarget (tribes); one in-flight attack per target; humans exempt (difficulty protections stay). Tests in AiAttackBehavior.test.ts (enclave dies, single-flight, human/peer exempt)
